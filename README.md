This repository contains my analysis of the Kaggle 2021 Data Science Survey, which collected responses from 25,973 participants across 171 countries. The survey provides valuable insights into the state of data science and machine learning, including trends in tools, technologies, salaries, and education.

Contents
Data Exploration: Initial exploration of the survey dataset, including response distributions and basic statistics

Data Visualization: Interactive and static visualizations of key survey findings

Demographic Analysis: Breakdown of respondents by country, education level, age, and gender

Technology Trends: Analysis of popular programming languages, ML frameworks, and cloud platforms

Career Insights: Examination of job titles, compensation trends, and industry distributions

Educational Paths: Analysis of formal education vs. online learning in data science

Key Findings
Python continues to dominate as the most used programming language among data professionals

Significant gender disparities persist in the field

Cloud platform adoption shows strong growth compared to previous years

The most common job title remains "Data Scientist" but with wide variation in responsibilities

Online learning platforms play a major role in skills development

Technical Approach
Implemented in Python using pandas for data manipulation

Visualization using matplotlib, seaborn, and Plotly

Statistical analysis to identify significant trends and correlations

Interactive dashboards for exploring the data

Requirements
Python 3.7+

Jupyter Notebook

pandas, numpy

matplotlib, seaborn, Plotly

scipy (for statistical tests)
